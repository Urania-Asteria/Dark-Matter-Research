# Dark-Matter-Research
Contains the Python code of all calculations, machine learning, graphing techniques used in this paper.

Parameter Fitting Using Data - has the processes as to how the rotation curves were fitted
Calculating velocity and density - contains the equations that used the data to calculate the velocity and density
Graphing density and velocity plots - has the packages used to create the graphs from the data
Symbolic Regression Calculations - has the processes of using symbolic regression to derive symbolic equations from the data
